Version: 2026-11-19 / 現行実装を基準

1. 基本方針
- GitHub Pagesで公開する個人ポートフォリオ。白背景、黒〜薄灰、極細線、余白を重視した建築的・編集的デザイン。装飾、一般的なナビゲーション、不要なヘッダー・フッターは設けない。
- 改修は必ず最新版の実ファイル（index.htmlと画像）から開始。既存機能・作品データ・字形・レイアウトを無断変更しない。デスクトップとスマートフォンで表示・操作を検証する。

2. 書体
- ロゴ、ページタイトル、ホーム外周文字、各サブページ下部の帰還ロゴ：提供済みShree Devanagari 714の字形。
- 本文、作品情報、メール等：提供済みAbsans Regularの字形。大文字・小文字・句読点を原文どおり維持。
- 現行HTMLではフォントを主にSVG輪郭データとして内蔵。フォントファイル自体を勝手に配布しない。

3. HOME
- 中央に11列×15行の正方形セルのグリッド。細い格子線、間隔の狭い二重フレーム。強調されたX=0/Y=0中心軸は設けない。
- 上辺に「SOT(EZUK)A」、左辺に「PROJECTS*ABOUT」、右辺に「*CONTACT*STORE」。文字の中心を対応するグリッド線に一致させる。「*」は区切り記号。
- 4語からそれぞれ1文字を欠落させ、上辺の同じ文字と交わる座標にページリンクを配置。PROJECTS末尾の複数形Sは欠落させない。4リンクのX座標は重複させない。再読み込み時に欠落位置を再選択。
- 外周の文字には直接リンクを設定しない。交点のクリック領域は確保する。
- 交点の黒いドットは直径3px。初期状態では非表示。上辺ロゴをクリック／タップ（キーボード操作も可）すると4点の表示／非表示を切り替える。ドットの表示状態にかかわらず交点リンクは維持。
- ホームにフッターは設けない。

4. サブページ
- PROJECTS / ABOUT / CONTACT / STORE。ヘッダーなし。下部の「SOT(EZUK)A」はホーム上辺と同じX座標で配置し、全体をホームへのリンクとする。

- 写真はGitHubリポジトリの images/ 直下に保存。命名規則：PJ番号_プロジェクト名_写真番号.jpg（例：PJ01_scale ruler_01.jpg、PJ02_KJM project_01.jpg）。png/webp等も現行コードの認識対象。

[2026-11-20] PROJECTS一覧のページ割当（厳密な定義）
- 1シートの作品番号範囲は5件分で固定。PJ番号 n は1以上の整数とする。
- 0始まりのシート番号: p(n) = floor((n - 1) / 5)。
- 1始まりの表示ページ番号: P(n) = floor((n - 1) / 5) + 1 = ceil(n / 5)。
- 1始まりのページ k の対象番号範囲: 5(k - 1) + 1 <= n <= 5k。
- 例: k=1 → PJ01–PJ05、k=2 → PJ06–PJ10、k=3 → PJ11–PJ15。
- 画像の有無・画像枚数・グリッド上の空き具合はページ割当を変更しない。
- 各シートのサムネイルは、その範囲に属し、表示可能な画像を持つ作品のみ。未登録番号や画像未提供の作品は空きとして扱い、後続の番号で埋めない。
- 各画像の四隅はグリッド交点に合わせ、最小3×3セルを維持する。配置できないことを理由に次のページへ繰り越さない。
- ページ矢印は最初と最後を循環する。作品詳細から戻る場合は直前のシート番号を維持する。

[2026-11-20] PROJECTS THUMBNAIL ORIENTATION — MANDATORY
- Determine original orientation from actual pixel dimensions Wsrc and Hsrc of the selected thumbnail photograph (default _01, PJ06 _05).
- Let Rsrc = Wsrc / Hsrc. The grid crop has integer dimensions w cells by h cells; since cells are square, Rcrop = w / h.
- If Rsrc > 1 (landscape), REQUIRE w > h.
- If Rsrc < 1 (portrait), REQUIRE w < h.
- If Rsrc = 1 (square), REQUIRE w = h.
- Every w and h is at least 3. The four crop corners MUST coincide with grid-line intersections; the crop stays within the 11-column by 15-row grid.
- The crop may change the original ratio within its orientation class; object-fit:cover remains in use. No rotation is permitted.
- The rule applies identically to every PROJECTS sheet, with five projects per sheet by ID: P(n) = floor((n - 1) / 5) + 1.
- Wait for actual image dimensions before treating a provisional placement as final; re-layout after load. If the image has not loaded, provisional square placement is allowed only until its orientation becomes available.
- Existing grayscale and grain effects apply to all thumbnail sheets; detail images retain their original color.

[2026-11-20] PROJECTS THUMBNAIL ALIGNMENT — TWO ALLOWED MODES
- Grid: 11 columns × 15 rows of square cells. Coordinates are measured in cell units from the top-left INNER grid corner: 0 <= x <= 11, 0 <= y <= 15.
- For each thumbnail choose exactly ONE alignment mode a from {0, 1/2}. Its upper-left corner is (x,y) = (i+a,j+a), where i,j are nonnegative integers.
- Its width w and height h are INTEGERS (cell units), with w >= 3, h >= 3. The other three corners are (x+w,y), (x,y+h), (x+w,y+h).
- Mode A (a=0): ALL FOUR corners lie on intersections of grid lines; x,y,x+w,y+h are integers.
- Mode B (a=1/2): ALL FOUR corners lie on centres of grid cells; x,y,x+w,y+h are half-integers (integer + 1/2).
- Bounds: 0 <= x, 0 <= y, x+w <= 11, y+h <= 15. Thus mode A requires 0 <= i <= 11-w and 0 <= j <= 15-h; mode B requires 0 <= i <= 10-w and 0 <= j <= 14-h.
- Mixed alignment (e.g. x integer but y half-integer, or some corners on lines and others on centres) is NOT permitted. The alignment mode is selected randomly for each thumbnail, along with its valid position and dimensions, subject to collision avoidance.
- Two thumbnails cannot overlap in area (touching edges is allowed). If an attempted placement overlaps, retry/backtrack without changing the project-to-sheet assignment.
- Preserve original orientation classification: landscape w>h, portrait w<h, square w=h. Keep the 5-project ID assignment P(n)=floor((n-1)/5)+1, monochrome/grain processing, original-colour detail images, and project-specific thumbnail number overrides (PJ06 uses _05).
